# Gole & Sabor

Projeto de um mini site desenvolvido como parte das atividades práticas do curso Transforme-se, utilizando **HTML5, Git e GitHub**.

## Sobre o projeto

O Gole & Sabor é um site fictício de uma loja de bebidas, criado para praticar a construção de páginas utilizando **HTML5 e estrutura semântica**.

O projeto apresenta informações sobre a loja, seus produtos e uma página de contato com formulário.

## Objetivo

Praticar conceitos fundamentais de HTML5, como:

- Elementos: **header, nav, main, section e footer**.
- Estrutura semântica;
- Títulos e parágrafos;
- Links de navegação;
- Imagens;
- Listas;
- Iframe;
- Formulários

## Tecnologias

- HTML5
- CSS (Inline)
- Git e GitHub (Para versionamento)
